# 셋이서 — 3인 협동 판 열둘

넷이서와 같은 타일 사전, 같은 물리로 만든 3인용 판 묶음. 사람이 하나 줄어든 것이 전부인데,
그 하나가 빠지면 규칙이 달라진다. 무거운 상자를 둘이 밀면 남는 건 하나, 어깨를 둘이 받치면
올라가는 것도 하나다. 판은 전부 "손이 하나 모자란다"는 전제 위에 세웠다.

파일은 `docs/셋이서/` 안에서 닫혀 있다. `grid.py` `solve.py` `run.py` 는 넷이서 것을
3인으로 고친 사본이고, 물리 상수(JUMP_UP 2 · JUMP_ACROSS 4 · SPRING_UP 5)는 그대로다.
확인은 `cd docs/셋이서 && python3 run.py` → `12판 · 486걸음 확인`.

## 1. 세 세계

| 단계 | 세계 | 결 |
|---|---|---|
| 1 | 놀이공원 | 정문·범퍼카·관람차·유령열차 차고. 밝고 기계적이다. 상자·어깨·스위치·누름판·컨베이어를 셋으로 배운다. |
| 2 | 유령 저택 | 현관 홀·서재·지하실·무도회장. 어둡고 순서가 중요하다. 열쇠 순서, 화물 포탈, 한 명을 묶어 두는 누름판. |
| 3 | 항구 | 야적장·크레인·방파제·등대. 넓고 무겁다. 앞에서 배운 것을 한 판에 겹쳐 놓았다. |

넷이서의 뒷마당·학교·도시·지하철과 겹치지 않는다.

## 3. 난이도 곡선

- 1-1~1-2: 협동 마디 둘. 상자와 어깨, 스위치 하나. 실패해도 되돌아올 수 있다.
- 1-3~1-4: 마디 셋. 되돌아오기(1-3)와 시간 제한(1-4)이 처음 들어간다. 어깨 둘을 다 쓰면
  밑에 둘이 남는다는 사실을 여기서 처음 만난다.
- 2-1~2-2: 마디 넷. 순서를 틀리면 되돌릴 수 없는 구간이 생긴다 — 2-1 의 열쇠 순서,
  2-2 의 화물 포탈.
- 2-3: 방향이 반대인 판. 협동은 단순(둘이 누름판)하고 남은 한 명의 조작 난도가 높다.
- 2-4~3-2: 마디 다섯. 누름판이 사람을 묶고, 그 사람의 탈출이 다른 사람 손에 달린 구조가 반복된다.
- 3-3: 다시 한 명 판. 어깨 둘(위로 네 칸)이 셋이서의 최대치라는 것을 정면으로 쓴다.
- 3-4: 마디 여섯. 앞의 패턴을 전부 한 줄로 잇는다. 어느 한 칸에서 순서를 틀리면 전부 다시.

## 4. 3인 협동 패턴

| 패턴 | 내용 | 쓴 판 |
|---|---|---|
| A. 어깨 하나 + 스위치 | 한 명이 받쳐 한 명을 넘기고, 넘어간 사람이 스위치를 밟아 남은 둘의 발판을 낸다 | 1-1, 1-2 |
| B. 어깨 둘 → 하나 | 둘이 받쳐야 위로 네 칸. 올라가는 건 하나뿐이고 둘은 남는다 | 1-4, 2-1, 3-3 |
| C. 무거운 상자 = 둘 | X 는 둘이 붙어야 밀린다. 미는 동안 남는 사람은 하나 | 1-4, 2-1, 2-2, 3-1, 3-2, 3-3, 3-4 |
| D. 한 명을 묶는 누름판 | 사람이 밟고 있어야 발판·셔터가 산다. 그 사람의 길은 나중에 남이 연다 | 1-2, 2-4, 3-1, 3-2, 3-4 |
| E. 사람 대신 상자 | 누름판을 상자가 밟게 해서 사람 하나를 되찾는다 | 1-3, 2-1, 2-2, 3-1, 3-3, 3-4 |
| F. 둘이 지키고 하나가 간다 | 누름판 둘을 둘이 밟으면 남는 건 하나. 그 하나는 도움을 못 받는다 | 2-3 |
| G. 열쇠로 합류 | 열쇠 밑이 같은 색 바닥이라 집는 순간 아래층으로 떨어져 일행과 만난다 | 1-3, 2-1, 2-4, 3-4 |
| H. 화물 포탈 | 상자만 포탈로 보낸다. 사람이 들어가면 발판 없는 자리에 나온다 | 2-2, 3-2 |
| I. 순서 잠금 | 스위치 먼저 열쇠 나중, 파란 먼저 빨간 나중. 틀리면 돌아갈 수 없다 | 2-1, 2-4, 3-4 |
| J. 3단 릴레이 | 하나가 밟고, 하나가 건너고, 하나가 위에서 문을 연다 | 2-4, 3-2, 3-4 |

패턴 D 의 실제 조작 주의점 하나: 누름판을 밟던 사람이 발판이 난 칸 쪽으로 걸어 나가면
머리가 발판 옆면에 걸린다. 반드시 반대쪽으로 한 칸 물러난 뒤 움직인다(2-4, 3-1, 3-2, 3-4 의 풀이가 그렇다).

## 6. 엔진 — 구현됐다 (v3.8.0)

`src/games/coop.js` 를 인원 수 매개변수 팩토리 `makeCoop({ id, name, crew, crewWord, stages, worlds, themes, … })` 로
바꾸고, 넷이서(`coop`, crew 4)와 셋이서(`trio`, crew 3, `src/games/trio.js`)를 같은 팩토리로 세웠다. 물리 상수·
타일 규칙은 공유하고, 모듈 수준의 가변 상태는 없다(게임마다 자기 살림살이). 시작 자리는 인원 수만큼 읽고,
`blocked()` 는 「셋이어야 시작한다」, 출구는 접속 인원(구경하는 사람 제외)에서 나온다. 세 세계의 색은 `trio.js`
의 THEME(놀이공원·유령 저택·항구, 통 이름 팝콘통·술통·드럼통). 판은 `docs/셋이서/export.py` 가
`src/games/trio-stages.js` 와 `test/trio-moves.json` 으로 내보낸다 — 넷이서 파일은 건드리지 않는다.
봇(`test/coop-bot.mjs` 와 그 위의 실전·넷 세상·동시 시뮬)은 `GAME=trio` 로 인원 셋을 읽는다.
규약 11 (새 게임 이름을 옛 앱이 모른다).

확인: `docs/셋이서/run.py` 12판 475걸음 · `GAME=trio node test/coop-play.mjs` 12/12(엔진) ·
`GAME=trio NOVID=1 node test/coop-cobot.mjs` 12/12(셋이 동시에) · `npm test` 602.

## 7. 새 타일 제안 (판에는 쓰지 않았다)

지금 사전으로는 만들 수 없어 포기한 것들. 전부 제안일 뿐이고 열두 판은 기존 타일만 쓴다.

1. **인원 누름판 `e` / 셔터 `E`** — 두 명이 동시에 올라야 눌리는 누름판. 지금 `p` `q` 는
   "하나라도 올라가 있으면" 눌린다(`solve.py` 의 `plate_held`, `coop.js:605`). 셋이서에서
   "정확히 둘이 밟아야 한다"는 규칙을 만들 수 없어 이 아이디어를 전부 버렸다.
2. **일방통행 발판 `_`** — 밑에서 통과하고 위에서는 못 내려오는 바닥. `=` 는 가장자리로
   돌아 내려갈 수 있어 진짜 되돌아갈 수 없는 길을 못 만든다.
3. **시한 스위치 `t` / 셔터 `T`** — 밟으면 N초만 열린다. 지금은 영구(`a`/`A`)이거나
   밟는 동안(`p`/`q`)뿐이라 "밟고 달려가야 하는" 긴장이 없다.
4. **내려오는 사다리 `L`** — 위층에서 밟으면 아래층까지 사다리가 내려온다. `n` 은 발판 한 칸이라
   층과 층을 잇지 못해서, 위에 올라간 사람이 아래 일행을 끌어올리는 장면을 못 만들었다.
5. **같은 색 열쇠 둘** — `grid.check` 가 한 색당 열쇠 하나만 허용한다. 둘을 허용하면
   "둘이 각자 하나씩 집어야 열리는 문"이라는 3인다운 자물쇠가 생긴다.

동사 쪽으로 하나 더: **상자 들어 올리기(throw)**. 사람이 가벼운 상자를 한 칸 위로 건네줄 수
있으면 3인 릴레이가 크게 늘어난다. 타일이 아니라 조작이라 여기서는 손대지 않았다.

## 5. v3.10.0 — 종탑 「약속의 종」(4-1) 과 새 장치 셋

위 4장에서 「지금 사전으로는 만들 수 없다」던 **시한 스위치 `t`/셔터 `T`** 와 **내려오는 사다리 `L`**(레버 `l`)을
v3.10.0 에서 엔진에 넣었고, 거기에 **전원 집결판 `c`/집결문 `C`** 를 더했다 — 셋이 청록 판 위에 0.3초 서면 문이
영구히 열리고 그 자리가 체크포인트가 되어, 죽어도 시작 자리가 아니라 자기 집결판에서 다시 산다 (되감기는 지운다).
세 장치를 한 판에 엮은 것이 종탑 「약속의 종」(120×42, 셋 모두)이다: 둘이 종추(`X`)를 밀어 셔터 → 둘의 어깨로 한 명을
종벽 위로 → 스위치 `a` 로 남은 둘의 계단 `n` → 셋이 집결판에서 체크포인트 → 중층 회랑 → 삭은 통로·10초 시한문·점멸
회랑 → 종탑 포탈로 꼭대기 → 구조 레버 `l` → 접이식 사다리 `L` 로 셋이 지상 출구에. 역할이 한 판 안에서 세 번 바뀐다.

확인: `python3 run.py` 13판 · `GAME=trio node test/coop-play.mjs` 13/13 ·
`GAME=trio STAGE='약속의 종' BUMP=1 NOVID=1 node test/coop-cobot.mjs` (사람 충돌·편도 2프레임 지연, 독립 월드 셋) 53초 클리어.
