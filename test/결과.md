- 아무도 안 잡았다 → `-1`

**⑨ 공이 네트 꼭대기 선에 정확히 떨어져도 점수가 갈린다**

- 한쪽이 점수를 얻었다 → `true`

**⑩ 사람이 없는 방에서 판이 끝나도 안 터진다**

- 혼자면 판을 안 끝낸다 → `true`

**⑪ 창을 숨겼다 켜도 입력이 안 굳는다**

- 달리는 중 → `true`
- 키가 풀렸다 → `false`

**⑫ 판 크기가 바뀌어도 사람이 화면 밖으로 안 나간다**

- 안쪽에 있다 → `true`

**⑬ 배구에서 판 크기가 바뀌어도 코트를 안 벗어난다**

- 오른쪽 코트 안 → `true`

**⑭ 손님이 깨진 꾸러미를 받아도 안 터진다**

- 살아 있다 → `true`

## 경우의 수 ⑮~㉖

**⑮ 서로 동시에 붙잡으면**

- 둘 다 잡은 상태로 안 엉킨다 → `true`

**⑯ 잡고 있던 사람이 방을 나가면**

- 잡았다 → `2`
- 손이 풀렸다 → `-1`
- 안 터진다 → `true`

**⑰ 잡고 있는데 내가 죽으면**

- 손이 풀렸다 → `-1`

**⑱ 배구 도중 한 편이 통째로 나가면**

- 처음엔 양쪽에 사람이 있다 → `true`
- 한쪽이 비었다고 말한다 → `true`
- 이긴 편 없이 끝난다 → `null`
- 빈 코트로 계속 돌지 않고 판을 접는다 → `true`
- 점수를 쌓지 않았다 → `true`
- 그래도 안 터진다 → `true`

**⑲ 게임을 빠르게 여러 번 갈아 끼워도**

- 살아 있다 → `true`
- 살림살이가 게임과 맞다 → `true`

**⑳ 공이 한 프레임에 두 사람에게 닿으면**

- 한 번만 튕긴다 (위로) → `true`
- 말도 안 되게 빠르지 않다 → `true`

**㉑ 판 크기를 모르는 채로 굴려도**

- 안 터진다 → `true`
- 그 뒤에도 성하다 → `true`

**㉒ 내 번호가 편 명단에 없으면**

- 편이 성한 값 → `true`
- 안 터진다 → `true`

**㉓ 슬라이딩으로 벽에 박으면**

- 벽 안쪽 → `true`
- 미끄러짐이 끝났다 → `true`

**㉔ 아주 오래 굴려도 (시계·자국)**

- 시계가 성하다 → `true`
- 자국이 안 쌓인다 → `true`

**㉕ 방장이 혼자일 때 판 끝내기**

- 끝났다 → `"over"`
- 세리머니가 돈다 → `true`

**㉖ 고르는 화면에서 메뉴를 열고 게임 바꾸기**

- 고르는 화면 → `"pick"`
- 메뉴가 열린다 → `true`
- 방 만들기가 없다 → `true`
- 코드로 입장이 없다 → `true`
- 게임 바꾸기도 없다 (이미 고르는 중) → `true`
- 끝내기는 있다 → `true`
- 닫힌다 → `true`
- 여전히 고르는 화면 → `"pick"`
